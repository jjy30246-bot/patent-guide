# 신길튼튼365정형외과 · 확장 이전 감사 영상

- 파일: `sinkil_365_expansion.mp4` (1920×1080, 30fps, 60초, H.264 + AAC 배경음악)
- 연출: 글자 단위 블러→선명 등장, 제목 금박 광택, 엔딩 금선 테두리, 흐르는 안개·금빛 먼지·빛 번짐, 매화/대나무 시차(parallax) 이동, 한지 위 먹물 방울 번짐 → 홍매화 가지가 그려지며 꽃이 핌 → 청록 대나무가 자라남 → 흩날리는 꽃잎과 문구 전환 → 병원명 + 낙관(튼튼) 엔딩
- 배경음악: 스크립트가 직접 합성(가야금풍 5음 음계 선율 + 패드 + 풍경 소리), 저작권 걱정 없음

## 다시 렌더링
`render.py`의 `build_texts()`에서 문구(예: 새 주소, 개원일)를 바꾼 뒤:
```
python3 render.py --fonts <폰트폴더> --out out.mp4          # 전체 영상
python3 render.py --fonts <폰트폴더> --out out.mp4 --preview 5,12,26   # 스틸 미리보기
```
폰트 폴더에는 Google Fonts의 `GowunBatang-Bold.ttf`, `GowunBatang-Regular.ttf`, `Myeongjo-EB.ttf`(나눔명조 ExtraBold), `Brush.ttf`(나눔손글씨 붓)를 두면 됩니다. 필요 패키지: numpy, Pillow, ffmpeg.
